# b2c-saas
# 수어 교육 웹앱 제작
## 요구사항
1. 프로젝트 개발 방향
구분	권장 방향

핵심 목적	한국수어 학습 및 AI 동작 인식 체험
주요 사용자	한국수어 입문자
개발 환경	PC 웹 우선
AI 기술	웹캠 기반 수어 동작 인식
초기 학습 범위	수어 표현 10~20개
운영 방식	무료·로컬 환경 중심
개발 원칙	핵심 기능 우선, 불필요한 기능 제외

2. 간소화한 기능 요구사항
ID	기능	상세 내용	우선순위
FR-01	수어 목록	학습 가능한 수어 표현 표시	필수
FR-02	수어 학습	선택한 수어의 영상과 의미 제공	필수
FR-03	영상 제어	재생·일시정지·반복 재생	필수
FR-04	웹캠 실행	카메라 접근 권한 요청 및 영상 표시	필수
FR-05	AI 동작 인식	학습한 수어 표현을 AI가 인식	필수
FR-06	학습 결과	정답·오답·인식 불가 표시	필수
FR-07	재도전	같은 수어를 다시 연습	필수
FR-08	수어 퀴즈	수어 영상을 보고 의미 맞히기	선택
FR-09	학습 기록	완료한 수어 표시	선택

3. 비기능 요구사항
ID	구분	요구사항
NFR-01	사용성	처음 사용하는 사람도 쉽게 학습 가능
NFR-02	접근성	음성 안내 없이도 모든 핵심 기능 사용 가능
NFR-03	호환성	PC Chrome·Edge 우선 지원
NFR-04	개인정보	웹캠 영상을 기본적으로 저장하지 않음
NFR-05	오류 처리	카메라 연결 및 인식 실패 시 안내
NFR-06	성능	일반적인 PC에서 영상 학습 및 AI 인식 가능
NFR-07	정확성	학습 대상별 인식 성공·실패 사례를 기록하고 검증
